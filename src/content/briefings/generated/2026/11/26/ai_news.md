# AI Daily Digest - 2026-11-26

## [AINews] Gemini 4 Neon marks GDM's full return as a Frontier Lab

## 🧠 模型进展
- Google Gemini 4 Neon 在付费 API 创下首日使用纪录，并已通过 Gemini 应用向 Workspace 客户开放，推动 DeepMind 重回前沿实验室讨论中心。
- 据用户报告，Claude Opus 5.6 正在 Claude Code 和聊天中进行 A/B 测试，被称为相对 5.5 的明显跃升（未确认）。
- Cognition 发布基于 Kimi K3 纯 RL 训练的 SWE-2.1，据称在最大推理下于 FrontierCode 2.0 接近前沿模型，并在 Devin 付费档免费两周。
- Z.ai 发布 750B 级 GLM-5.4 Loop Transformer，复用共享 28 层块两次迭代以提升推理深度，并计划安全加固后开放权重。
- DeepMind/Kaggle 的 Humanity's First Exam 中 GPT-6.2 Astra 以 90.7% 领先，Sol 和 Neon 紧随其后，显示顶级模型在家庭级可靠性上仍有差距。

## 🤖 Agent/产品进展
- Claude artifacts 现可作为桌面应用安装，支持连接器和通知，并在所有套餐中进入 beta。
- MCP 两周年之际，Tasks 面向长时服务器操作正式可用、Skills over MCP 正在推出、File Uploads 即将推出，Claude 连接器已超过 10,000 个。
- Google 为 Neon 推出实验性 anti-slop 前端设计技能，并正式开放八个 Workspace MCP 服务器和 gwscli，每产品每天免费 5,000 次请求。
- OpenAI Agents API 新增按会话预算控制和托管预热沙箱，强化 Agent 部署的成本与运行管理。
- Songe 开源本地代理/训练循环，可在机器空闲时用本地轨迹通过 on-policy 自蒸馏微调 LoRA 适配器，并带提升门禁和回归检查。

## 🔬 AI for Science
- Anthropic 内部 Claude 研究模型据称在 GitHub 给出 VP≠VNP（P vs NP 的代数类比）证明，OpenAI 随后发布自己的证明，但该结果不直接推出 P≠NP。
- OpenAI 预印本显示 GPT-6 通过推理和代码设计新蛋白形状与序列，湿实验验证 14/107 重测序蛋白有结合、128/182 小型抗体和 179/272 抗体片段保留结合。
- 业余研究者用 Codex 和 Astra 搜索 Kepler/TESS 数据，一个 13.8 天信号被 SETI 天文学家独立确认，并标记 49 个 TESS 候选。
- 历史学家称 GPT-6.2 Astra 在 22 分钟内识别出 1808 年 Yale 匿名素描本作者为 vicomte de Chabot，并找到笔迹和行程匹配的微缩日记。

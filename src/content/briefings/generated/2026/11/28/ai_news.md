# AI Daily Digest - 2026-11-28

## How Clay Builds GTM Agents — Jeff Barg, Head of AI

## 🧠 模型进展
- Clay 认为多数公司过早开展 post-training，只有在推理支出达到约 1000 万至 1 亿美元后才可能因降本而划算。
- Clay 计划先用更便宜的开源权重模型，再基于自有工具与查询 post-train 更小模型，以在特定任务上接近 Opus 表现。
- Clay 的线索资格评估已约一年饱和，前沿模型价值更多转向编排与深度研究而非简单信息抽取。
- Clay 即将推出按任务自动选择模型的 router，以替代让普通用户手动查看和选择模型。
- 借助 TypeSafe Jev 类分类器，Clay 估算对全球 4000 万家公司做 ICP 匹配约需 1500 美元。

## 🤖 Agent/产品进展
- Clay 将 Sculptor 从工具循环重构为基于 Pi harness 的 coding agent，在云沙箱中运行 Clay CLI。
- Clay 推出 Audiences 数据层，统一 CRM 与 Gong 记录并做实体解析，让 agent 同时看到客户和活动结果。
- Clay 计划发布沙箱化 agent，允许 Claude Code 等外部 harness 免费调用 Clay 工具，目标是取得与自家 agent 接近的结果。
- Clay 内部使用已接近 50/50 分布在自家 agent 与外部 harness 之间，并已提供 CLI/API 支持 Claude Code 和 Codex。
- Clay 近期上线 25 至 30 个新集成，并用 LangSmith、请求限流和暂停恢复机制应对 agent 规模化带来的推理尖峰。
